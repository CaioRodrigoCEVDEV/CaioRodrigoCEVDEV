## 👨‍💻 Sobre mim

Construo software na prática: sistemas web, APIs e produtos próprios. A maior parte do meu trabalho está no backend — modelagem de dados, autenticação, integrações e automação de processos — mas também atuo no frontend quando o projeto pede uma interface completa e funcional.

Gosto de pegar um problema real e transformá-lo em uma aplicação que funciona, seja um painel administrativo, uma API, uma ferramenta desktop ou um produto que usa IA local. Também trabalho com Linux e infraestrutura para manter tudo rodando de forma simples e confiável.
